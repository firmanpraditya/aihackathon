Sparepart MA1

Dashboard manajemen sparepart real-time — klasifikasi otomatis Fast/Slow/Deadstock, pencatatan pengambilan per mesin, dan alert stok kritis. Semua berbasis data BASE DATA & TRANSAKSI yang sudah ada.
🔗 Modul CMMS — Gunakan format kode mesin MCH-001 dan kode sparepart sesuai kolom "Item number" agar terintegrasi dengan Tim C & E
🔴 Sebelum
  • Cek stok manual — tidak tahu mana yang kritis tanpa buka Excel satu per satu
  • Data transaksi dan data base (min/max) ada di file terpisah, tidak terkoneksi
  • Tidak ada alert otomatis saat stok mendekati batas minimum
  • Klasifikasi Fast/Slow/Deadstock dilakukan manual dan memakan waktu berhari-hari
🟢 Sesudah
  • Dashboard real-time: langsung tahu stok mana yang kritis (merah) atau aman (hijau)
  • Klasifikasi Fast/Slow/Deadstock otomatis berdasarkan frekuensi transaksi
  • Setiap pengambilan sparepart tercatat otomatis beserta peruntukan mesinnya
  • Alert email otomatis saat stok di bawah minimum

Buatkan Google Apps Script (Code.gs) untuk sistem manajemen sparepart.

STRUKTUR GOOGLE SHEETS "Dashboard Sparepart MA1":

Sheet "BASE DATA" kolom:
Site | Kategori Item | Kode Item | Nama Item | Min | Max

Sheet "TRANSAKSI" kolom:
Physical date | Reference | Number | Site | Warehouse | Batch number | Location |
Item number | Journal Name | Search name | Quantity | Issue status | Journal Description
(Catatan: Physical date berupa angka serial Excel, Quantity negatif = barang keluar)

Sheet "STOK SEKARANG" - akan diisi otomatis, kolom:
Kode Item | Nama Item | Min | Max | Total Keluar Bulan Ini |
Total Keluar 3 Bulan | Stok Estimasi | Status Stok | Kategori | Terakhir Diambil

Sheet "LOG PENGAMBILAN" kolom:
Timestamp | Kode Item | Nama Item | Jumlah Diambil | Peruntukan/Keterangan | Stok Sebelum | Stok Sesudah

FUNGSI YANG DIBUTUHKAN:

1. fungsi updateStokSekarang():
   - Baca semua item dari BASE DATA
   - Hitung "Total Keluar Bulan Ini" dari sheet TRANSAKSI (filter bulan berjalan, kolom Quantity)
   - Hitung "Total Keluar 3 Bulan" dari TRANSAKSI (filter 3 bulan terakhir)
   - Cari tanggal terakhir item diambil dari TRANSAKSI
   - Konversi Physical date dari angka serial Excel ke tanggal normal
   - Klasifikasi otomatis:
     * FAST MOVING = total keluar 3 bulan > 0 dan stok mendekati Min
     * SLOW MOVING = total keluar 3 bulan > 0 tapi stok masih aman
     * DEADSTOCK = total keluar 3 bulan = 0 (tidak ada transaksi sama sekali)
   - Tentukan Status Stok:
     * KRITIS = Stok Estimasi <= Min
     * WASPADA = Stok Estimasi antara Min dan Max
     * AMAN = Stok Estimasi >= Max
   - Tulis semua hasil ke sheet "STOK SEKARANG"
   - Warnai baris: merah=KRITIS, kuning=WASPADA, hijau=AMAN

2. fungsi catatPengambilan(kodeItem, namaItem, jumlah, keterangan):
   - Kurangi Stok Estimasi di STOK SEKARANG
   - Tambah baris baru di LOG PENGAMBILAN dengan timestamp
   - Tambah baris baru di TRANSAKSI dengan data lengkap
   - Kembalikan: { sukses: true/false, stokSebelum, stokSesudah, statusBaru }

3. fungsi getDataDashboard():
   - Ambil semua data dari STOK SEKARANG
   - Hitung summary: total item, jumlah kritis, jumlah fast moving, jumlah deadstock
   - Kembalikan sebagai JSON untuk ditampilkan di Web App

4. fungsi kirimAlertEmail(emailTujuan):
   - Cari semua item dengan Status Stok = KRITIS
   - Kirim email ke emailTujuan berisi daftar item kritis beserta stok saat ini vs minimum
   - Format email: tabel rapi dengan nama item, stok saat ini, stok minimum

5. fungsi doGet(e):
   - Return HtmlService.createHtmlOutputFromFile('index')
   - Untuk serve Web App

6. Buat Time-driven trigger agar updateStokSekarang() berjalan otomatis setiap hari jam 07.00

Tambahkan komentar penjelasan di setiap bagian kode.
💡
Jika ada error saat menjalankan: copy pesan error → paste ke Gemini: "Tolong perbaiki error ini: [paste error]". Gemini akan langsung perbaiki kodenya.

Test Script & Isi Stok Awal
▾

Sebelum deploy, test dulu apakah script berjalan dengan benar.

Cara test fungsi updateStokSekarang():

  1. Di editor Apps Script → pastikan file Code.gs aktif (klik namanya)
  2. Di dropdown fungsi (sebelah tombol Run), pilih updateStokSekarang
  3. Klik tombol Run ▶
  4. Jika pertama kali: akan muncul popup minta izin → klik Review permissions → Advanced → Go to Sparepart MA1 → Allow
  5. Buka sheet "STOK SEKARANG" di Google Sheets → cek apakah data sudah terisi
⚠️
Stok Estimasi masih kosong! Kolom "Stok Estimasi" perlu diisi manual dulu dengan stok aktual saat ini. Setelah itu, setiap pengambilan via Web App akan otomatis mengurangi nilainya.

Cara isi stok awal:

  1. Buka sheet "STOK SEKARANG"
  2. Temukan kolom "Stok Estimasi"
  3. Isi angka stok aktual untuk setiap item berdasarkan hasil cek fisik gudang
  4. Setelah diisi, jalankan lagi fungsi updateStokSekarang() → status dan kategori akan otomatis terupdate
💡
Untuk demo/prototype, cukup isi stok estimasi untuk 10-20 item dulu. Pilih campuran: beberapa item stok kritis, beberapa aman, dan beberapa deadstock agar dashboard terlihat bervariasi saat demo.

Setup Alert Email Otomatis
▾

Agar supervisor otomatis dapat notifikasi saat ada stok kritis tanpa perlu membuka dashboard, setup trigger email otomatis.

Cara setup trigger otomatis:

  1. Di Apps Script → klik ikon jam ⏰ (Triggers) di menu kiri
  2. Klik "+ Add Trigger" di pojok kanan bawah
  3. Set Choose which function to run: kirimAlertEmail
  4. Set Select event source: Time-driven
  5. Set Select type of time based trigger: Day timer
  6. Set Select time of day: 7am to 8am
  7. Klik Save
💡
Pastikan di dalam fungsi kirimAlertEmail() di Code.gs, alamat email tujuan sudah diisi dengan email supervisor atau kepala gudang. Contoh: const emailTujuan = "supervisor@perusahaan.com";

Buat Web App + Setup QR Code per Mesin
▾

Fitur unggulan Tim E adalah QR Code per mesin — scan → form langsung terbuka dengan kode mesin sudah terisi otomatis.

📱
Cara kerja QR Code per mesin: Setiap mesin punya URL unik dengan parameter kode mesin di akhirnya. Contoh: [URL web app]?mesin=MCH-001. QR Code dibuat dari URL ini, sehingga saat di-scan langsung buka form dengan MCH-001 sudah terisi.
Buatkan Google Apps Script + HTML untuk monitoring 49 mesin produksi.

GOOGLE SHEETS "Monitoring Mesin - Engpro":
- Sheet "Laporan Mesin": Timestamp, Kode Mesin, Jenis Laporan

  Deskripsi, Nama Pelapor

  Tgl Perawatan Terakhir, Total Jam Operasi Kumulatif
- Sheet "Jadwal Perawatan": Kode Mesin, Jadwal Berikutnya, Status, Prioritas

HALAMAN 1 - FORM LAPORAN (dibuka via QR Scan):

- Input Nama Pelapor
- Tombol "Kirim Laporan"
