Avenger

Analisa otomatis data akuisisi produksi — bandingkan aktual vs standar R&D, hasilkan laporan harian yang konsisten dan bebas interpretasi ganda.
🔴 Sebelum
  • Tarik data manual dari software — minimal 2 jam/hari
  • Setiap orang bisa punya interpretasi berbeda dari data yang sama
  • Tidak ada standar pelaporan yang konsisten
  • Potensi mutu produk terlewat karena analisa lambat
🟢 Sesudah
  • Upload Excel → komparasi otomatis vs standar R&D
  • Perbandingan standar vs aktual langsung terlihat jelas
  • Laporan harian terkirim otomatis setiap pagi via email
  • Satu interpretasi yang seragam untuk semua pihak
Langkah-langkah Pembuatan Prototype
1
Persiapan Data & Encode
▾

Sebelum apapun, semua data yang akan dimasukkan ke sistem AI harus di-encode terlebih dahulu untuk menjaga kerahasiaan data perusahaan.

⚠️
Wajib dilakukan: Ganti nama produk asli → PRD-001, PRD-002. Ganti kode batch → BCH-001. Simpan tabel mapping di file lokal yang tidak diupload ke AI.

Yang perlu disiapkan:

  1. Export data dari software akuisisi dalam format Excel (file .xlsx)
  2. Encode nama produk dan kode batch — buat tabel mapping terpisah
  3. Siapkan dokumen standar parameter dari R&D (sudah di-encode)
  4. Tentukan email tujuan laporan: manajer produksi, supervisor QC
2

4
Buat Apps Script — Komparasi & Email Otomatis
▾

Apps Script adalah "robot" yang bekerja otomatis di balik layar. Kita tidak perlu menulis kode sendiri — minta Gemini membuatkannya.

Cara membuka Apps Script:

  1. Di Google Sheets → klik menu Extensions (atau "Ekstensi")
  2. Klik Apps Script
  3. Editor kode akan terbuka di tab baru
  4. Hapus semua kode yang sudah ada (Ctrl+A → Delete)
  5. Copy-paste kode dari Gemini (gunakan prompt di bawah)
  6. Klik tombol Save (ikon disket) → klik Run → izinkan akses
Saya punya Google Sheets "Analisa Data Produksi" dengan:

Sheet "Data Aktual" kolom:
Timestamp, Kode Produk, Kode Batch, Suhu (°C), Berat (gram), Tekanan (bar)
[sesuaikan dengan parameter aktual di datamu]

Sheet "Standar R&D" kolom:
Kode Produk, Parameter, Nilai Min, Nilai Max, Satuan, Risiko

Tolong buatkan Google Apps Script yang:
1. Setiap hari jam 07.00 baca semua data dari hari sebelumnya
2. Bandingkan setiap nilai aktual dengan standar yang sesuai
3. Isi sheet "Hasil Analisa" dengan semua kolom data + STATUS (SESUAI/TIDAK SESUAI) + DEVIASI
4. Warnai baris: hijau jika SESUAI, merah jika TIDAK SESUAI
5. Buat ringkasan: total data, jumlah sesuai, jumlah tidak sesuai per parameter
6. Kirim email ke [isi email manajer] dengan ringkasan dan link ke sheet

Tambahkan komentar penjelasan di setiap bagian kode agar mudah dipahami.
💡
Jika ada error saat menjalankan script: copy pesan error yang muncul → paste ke Gemini dengan kalimat "Tolong perbaiki error ini: [paste error]"
5
Upload Standar R&D ke NotebookLM
▾

NotebookLM bisa "membaca" dokumen standar R&D dan menjawab pertanyaan spesifik tentang isinya — sangat berguna saat perlu cek batas toleransi atau prosedur penanganan deviasi.

  1. Buka notebooklm.google.com → klik "+ New Notebook"
  2. Klik "Add Sources" → upload dokumen standar R&D (sudah di-encode)
  3. Tunggu proses indexing selesai (biasanya 1-2 menit)
  4. Ketik pertanyaan di kotak chat
Contoh pertanyaan ke NotebookLM:

- "Berapa batas toleransi suhu untuk produk PRD-001?"
- "Apa dampak jika berat produk PRD-002 berada di bawah standar minimum?"
- "Prosedur apa yang harus diikuti jika tekanan menyimpang lebih dari 10%?"
- "Rangkumkan semua parameter kritis yang mempengaruhi mutu produk PRD-001"
- "Bandingkan standar parameter antara PRD-001 dan PRD-002"

  3. Sekarang kamu punya 2 file: Code.gs (logika) dan index.html (tampilan)
  4. Gunakan prompt di bawah untuk generate kedua file sekaligus dari Gemini
💡
Minta Gemini untuk generate kode dalam 2 bagian terpisah: pertama kode untuk Code.gs, lalu kode untuk index.html. Lebih mudah dicopy satu per satu.

5
Deploy Web App & Buat QR Code
▾

Setelah kode selesai, deploy Web App agar bisa diakses dari HP manapun.

  1. Di Apps Script → klik Deploy → New Deployment
  2. Klik ikon ⚙️ → pilih Web App
  3. Set Execute as: Me
  4. Set Who has access: Anyone
  5. Klik Deploy → copy URL yang muncul
  6. Test: buka URL tersebut dari HP — Web App harus bisa dibuka
✅
Buat QR Code dari URL: Buka qr-code-generator.com → paste URL Web App → Generate → Download → Print dan tempel di area kerja operator.
6
Tambahkan Narasi AI dari Gemini API
▾

Setelah sistem dasar berjalan, tambahkan integrasi Gemini agar laporan email menyertakan analisa narasi otomatis.

Cara dapatkan Gemini API Key:

  1. Buka aistudio.google.com
  2. Klik "Get API Key" di menu kiri
  3. Klik "Create API Key" → copy key yang muncul
  4. Simpan key ini — jangan bagikan ke orang lain
Di Apps Script yang sudah ada, tambahkan fungsi getNarasiAI(dataFail) yang:

1. Menerima input: array data mesin yang FAIL beserta nama parameter dan nilainya
2. Memanggil Gemini API menggunakan UrlFetchApp.fetch() dengan API Key
3. Prompt ke Gemini:
   "Berikut data mesin Auto Pack yang parameter-nya tidak sesuai standar hari ini:
   [data]. Berikan analisa singkat: potensi penyebab, dampak ke kualitas produk,
   dan rekomendasi tindakan. Maksimal 3 paragraf singkat, bahasa mudah dipahami."
4. Mengembalikan teks narasi dari Gemini
5. Narasi disimpan ke sheet "Rekap Harian" kolom "Narasi AI"
6. Narasi juga disisipkan di body email laporan harian

Gunakan model: gemini-1.5-flash
Endpoint: https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent
Simpan API Key sebagai: const GEMINI_API_KEY = 'isi-api-key-di-sini';

Buat Web App + Setup QR Code per Mesin
▾

Fitur unggulan Tim E adalah QR Code per mesin — scan → form langsung terbuka dengan kode mesin sudah terisi otomatis.

📱
Cara kerja QR Code per mesin: Setiap mesin punya URL unik dengan parameter kode mesin di akhirnya. Contoh: [URL web app]?mesin=MCH-001. QR Code dibuat dari URL ini, sehingga saat di-scan langsung buka form dengan MCH-001 sudah terisi.
Buatkan Google Apps Script + HTML untuk monitoring 49 mesin produksi.

GOOGLE SHEETS "Monitoring Mesin - Engpro":
- Sheet "Laporan Mesin": Timestamp, Kode Mesin, Jenis Laporan
  (Rutin/Kerusakan/Serah Terima/Selesai Perbaikan), Kondisi Mesin
  (Normal/Perlu Perhatian/Rusak/Dalam Perbaikan), Jam Operasi,
  Deskripsi, Nama Pelapor
- Sheet "Master Mesin": Kode Mesin, Lokasi, Interval Perawatan (hari),
  Tgl Perawatan Terakhir, Total Jam Operasi Kumulatif
- Sheet "Jadwal Perawatan": Kode Mesin, Jadwal Berikutnya, Status, Prioritas

FITUR WEB APP:

HALAMAN 1 - FORM LAPORAN (dibuka via QR Scan):
- Baca parameter URL ?mesin=MCH-001 → isi otomatis kode mesin
- Dropdown Jenis Laporan dan Kondisi Mesin
- Input Jam Operasi hari ini dan Deskripsi kondisi
- Input Nama Pelapor
- Tombol "Kirim Laporan"
- Setelah kirim: tampilkan konfirmasi + info jadwal perawatan mesin ini

  Hijau=Normal, Kuning=Perlu Perhatian, Merah=Rusak, Biru=Dalam Perbaikan
- Counter di atas: mesin per kondisi

- Update Total Jam Operasi di Master Mesin tiap ada laporan baru
